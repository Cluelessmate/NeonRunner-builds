# NEON//RUNNER

A fast PS1-style first-person parkour run through a neon cyberpunk city, inspired by Ghostrunner.
Wall-run across giant ad screens, grapple over the widest gaps, vault and mantle across rooftops, cut down gunners, rushers, snipers and riot shields with a neon katana, and draw a pistol in mid-air to slow time. Six levels, ending in a boss fight.

## Controls

Keyboard and mouse actions can be rebound in Settings → Controls. Gamepads are supported.

| Action | Keyboard / mouse | Gamepad |
|---|---|---|
| Move / look | WASD / mouse | Sticks |
| Jump / wall-jump | Space | A |
| Dash (dash right before a shot hits to dodge it) | Shift | RB |
| Slide | Ctrl | B |
| Katana: slash, lunge, deflect shots | Left mouse | RT |
| In the air: draw pistol + bullet time | Hold right mouse | LT |
| Grapple to a glowing anchor | E | LB |
| Retry from checkpoint | R | View |
| Pause | Esc | Menu |

**Tips:** hold forward and jump at a wall to wall-run. Run into anything waist-high to vault it, and jump into ledges to mantle up. One hit kills you, and one hit kills enemies. Riot shields only break from behind or when you parry a bolt back at them. Every level hides 3 data shards.
